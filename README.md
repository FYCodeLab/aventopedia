## 🎨 Design System & Visual Style

The interface is built with a custom **Neo-Brutalist / Retro-Pop** UI aesthetic:

* **Visual Style:** High-contrast Neo-Brutalism characterized by thick black borders (`3px solid`), sharp offset drop shadows (`box-shadow`), rotated badging (`transform: rotate()`), and a subtle paper-grid background.
* **Color Palette:**
  * 💛 **Yellow:** `#ffd84d` (Buttons & accents)
  * 🌸 **Pink:** `#ff78aa` (Search toggles & highlights)
  * 💜 **Violet:** `#6f5cff` (Action buttons & pricing accents)
  * 🌿 **Mint:** `#a8e6cf` (Category kickers & badges)
  * 📜 **Background:** `#fbf5e8` paper canvas with grid overlay
* **Typography:** 
  * **Display Headlines:** Google Font **Passion One** (Impact / Display style)
  * **UI & Body:** Google Font **Inter** (Clean geometric sans-serif)
* **Layout & Responsiveness:** 
  * Full-viewport locked container (`100vw` / `100dvh`) eliminating unwanted page scroll.
  * Responsive CSS Grid switching between side-by-side desktop view, stacked mobile portrait view, and optimized mobile landscape view.
* **Interactivity:** Integrated live JavaScript search bar, interactive theme filter tabs, touch swipe support, and keybindings (left/right arrows).
